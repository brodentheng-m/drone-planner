# Changelog

All notable changes to the Educational Drone Flight Path Planner project.

---

## 📌 v1.1.4 - Latest Version
*Enhance UI beauty and add manual code editing*

### ✅ Added
- Beautiful modern styling with **Inter** font
- Improved color scheme with **glow effects**
- Smooth transitions and hover effects
- Scaled drone model to **actual drone size** (100mm x 100mm)
- Changed code output to **editable textarea**
- Added **Apply** button to apply manually edited code
- Improved button styling with shadows and transforms
- Enhanced panel borders and spacing
- Updated scrollbar styling

### 🎯 Key Features
- **Camera Lock During Typing**: Camera controls are now **disabled** when editing code
- **Bright Green Typing Indicator**: Visual feedback with pulsing green border shows when in typing mode
- **Escape Key Support**: Press **Escape** to exit typing mode
- **Updated Python Scripts**: All example scripts compatible with v1.1.4 API

### 📁 Files Updated
- `showcase.py` - Full feature demonstration
- `obama.py` - Obama portrait flight path
- `swarm_showcase.py` - 20-drone swarm formation
