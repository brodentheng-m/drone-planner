## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- npm 7+
- Python 3.7+
- Educational drone hardware (optional, for real flight)

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

Open in browser: http://localhost:5173

### Build
```bash
npm run build
```

## ✨ Features

- ✅ Visual flight path planning in 3D
- ✅ Real-time simulation
- ✅ Python code generation for educational drones
- ✅ Multi-drone swarm support
- ✅ Command palette with all drone commands
- ✅ Manual code editing with live preview
- ✅ Camera lock during typing (v1.1.4)
- ✅ Bright green typing indicator (v1.1.4)

## 🎯 Usage

1. **Plan your flight**: Use the command palette to add commands
2. **Simulate**: Click Play to see the drone movement in 3D
3. **Generate code**: Copy the generated Python code
4. **Fly**: Run the code on your educational drone
